# ⚜️ CyberScout Academy DZ | أكاديمية الكشاف الرقمي

منصة تعليمية وتدريبية رقمية تفاعلية موجّهة لأفراد وقادة **الكشافة الإسلامية الجزائرية**، تجمع بين الأصالة الكشفية والتقنيات الحديثة (الذكاء الاصطناعي، التوجيه الصوتي بالدارجة الجزائرية، وتطبيقات الويب التقدمية PWA) لتعزيز المهارات الرقمية والتأهيل الكشفي.

---

## ✨ المميزات الرئيسية

- 🎙️ **توجيه صوتي بالدارجة الجزائرية:** تجربة تفاعلية ناطقة باللهجة الجزائرية لتقريب المفاهيم الكشفية والتقنية لجميع الفئات العمرية بأسلوب سلس وقريب.
- 🤖 **مساعد ذكي مدمج (AI Chat Engine):** محرك محادثة مدعوم بالذكاء الاصطناعي للإجابة الفورية عن استفسارات الكشافين والقادة وتوجيههم في المسارات التدريبية.
- 📱 **تطبيق ويب تقدمي (PWA):** إمكانية تثبيت التطبيق مباشرة على هواتف Android و iOS وأجهزة الحاسوب بواجهة مستقلة وأيقونات متكيفة (`Maskable Icons`).
- 🎨 **تصميم تفاعلي وانتقالات سلسة:** واجهة مستخدم عصرية مزوّدة بحركات انتقال انسيابية (Transition Animations) تضمن تجربة استخدام مريحة وسريعة.
- 🛡️ **محتوى رقمي وتوعوي:** وحدات تعليمية تجمع بين التقاليد الكشفية، الثقافة الرقمية، والسلامة المعلوماتية بأسلوب تطبيقي.

---

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):** HTML5, CSS3, JavaScript (ES6+)
- **تطبيقات الويب التقدمية:** Web App Manifest, Service Workers (PWA)
- **الذكاء الاصطناعي والصوتيات:** In-App AI Chat Engine, Web Audio / Speech APIs

---

## 🚀 طريقة التثبيت والتشغيل

### أولاً: التثبيت المباشر كتطبيق على الهاتف أو الحاسوب
1. افتح رابط التطبيق المنشور عبر متصفح **Google Chrome** أو **Safari** أو **Microsoft Edge**.
2. اضغط على خيار **تثبيت التطبيق (Install App)** أو **إضافة إلى الشاشة الرئيسية (Add to Home Screen)**.
3. سيُثبّت التطبيق بأيقونته الرسمية ويعمل كأي تطبيق مستقل على جهازك.

### ثانياً: التشغيل المحلي للمطورين
1. نزّل ملفات المشروع من قسم **Releases** أو عبر زر **Code > Download ZIP**.
2. فك الضغط عن المجلد وافتحه باستخدام محرر الأكواد (مثل VS Code).
3. شغّل ملف `index.html` عبر خادم محلي (مثل إضافة **Live Server**) لضمان عمل ميزات الـ PWA والصوت بشكل كامل.
